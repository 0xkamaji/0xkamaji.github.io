# Poncho Bear Labs

A lightweight GitHub Pages starter for reverse engineering writeups, security projects, and cyber notes.

## Publish on GitHub Pages

1. Create a GitHub repository named `yourusername.github.io`.
2. Copy these files into that repository.
3. Push to the `main` branch.
4. In GitHub, go to `Settings` -> `Pages`.
5. Under `Build and deployment`, select `Deploy from a branch`.
6. Choose `main` and `/root`.

## Write a new post

Add a Markdown file under `_posts` with this filename format:

`YYYY-MM-DD-title.md`

Example front matter:

```yaml
---
layout: post
title: "My New Writeup"
categories: [writeup]
excerpt: "One-sentence summary of the post."
---
```
